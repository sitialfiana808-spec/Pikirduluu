# 🧠 PikirDulu - Asisten Belajar Anti-Copas

**PikirDulu** adalah aplikasi web edukasi yang dirancang untuk membantu siswa memahami dan menyelesaikan tugas sekolah tanpa ketergantungan pada jawaban instan dari AI. Aplikasi ini mengedepankan metode *scaffolding* (bimbingan bertahap) agar siswa tetap melatih kemampuan berpikir kritisnya.

## ✨ Fitur Utama
1. **Beranda**: Pengenalan konsep belajar cerdas dan pentingnya melatih kemandirian berpikir.
2. **Penyelesaian Tugas (Panduan Bertahap)**: Siswa diminta menuliskan usaha awal mereka terlebih dahulu sebelum mendapatkan peta berpikir dan petunjuk langkah demi langkah (bukan jawaban langsung).
3. **Kuis Pemahaman**: Latihan soal interaktif dilengkapi pembahasan langsung untuk menguji pemahaman konsep.
4. **Motivasi Belajar**: Kumpulan kutipan penyemangat agar siswa tidak mudah menyerah saat menghadapi tugas sulit.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik halaman web.
- **CSS3**: Desain responsif modern menggunakan Flexbox, Grid, dan animasi transisi.
- **JavaScript (Vanilla JS)**: Logika navigasi SPA (*Single Page Application*), petunjuk bertahap, dan sistem penilaian kuis.

## 🚀 Cara Menjalankan di GitHub Pages
1. Buat repositori baru di GitHub (misalnya: `pikirdulu-app`).
2. Unggah keempat file (`index.html`, `style.css`, `script.js`, dan `README.md`) ke repositori tersebut.
3. Buka tab **Settings** > **Pages** pada repositori GitHub.
4. Pada bagian **Branch**, pilih `main` (atau `master`) lalu klik **Save**.
5. Tunggu beberapa saat, dan aplikasi web siap diakses melalui tautan GitHub Pages yang muncul.
